# スカウトと配合

## スカウトアタック

スカウトアタックで、野生のモンスターを仲間にします。

| 項目 | 内容 |
| --- | --- |
| 使い方 |   |
| スカウト率の上げ方 |   |
| 失敗したとき |   |
| 連れて歩ける数 |   |

## スカウトできるモンスター

スカウトできるモンスターは、コロシアムのマスターランクが上がるほど増えます。くわしくは[コロシアム](/play/colosseum)へ。

## 配合

育てた仲間を2体配合して、新しいモンスターを生みます。

| 項目 | 内容 |
| --- | --- |
| 配合する場所 | 旅の扉のほこらの配合の神官 |
| 子が受け継ぐもの | 両親のSPの半分 |

組み合わせは[配合表](/monsters/haigou)にまとめます。
