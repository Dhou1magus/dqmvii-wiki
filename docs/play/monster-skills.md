# 仲間のスキルと特性

## SPのもらい方

- Lvアップ1回でSPが1増える
- 配合で生まれた子は、両親のSPの半分を引き継ぐ
- 一度振ったSPは戻せない

## スキル

仲間1体に3つのスキルがあり、それぞれ150SPまで振れます。振ったSPが必要SPに届くと、呪文・特技や能力アップを覚えます。

150SPまで振ると、上位のスキルに進めるものもあります。

| 必要SP | 覚えるもの |
| --- | --- |

スキルごとの中身は[スキル一覧（仲間）](/monsters/skills)にまとめます。

## 特性

Lvとプラス値が決まった値に届くと、特性が開きます。

| 開く条件 | 特性 | メモ |
| --- | --- | --- |
| Lv1 |   |   |
| Lv60 |   |   |
| Lv120 |   |   |
| プラス値+25 |   |   |
| プラス値+50 |   |   |
| プラス値+100 |   |   |

特性ごとの効果は[特性一覧](/monsters/traits)にまとめます。
