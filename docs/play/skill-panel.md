# 職業とスキルパネル

スキルパネルは、すべての職業と武器のエリアが1枚にまとまった六角形の盤です。呪文・特技・能力アップはパネルとして並んでいて、どれも同じSPで取ります。

## 決まりごと

- パネルは、取ったパネルと接しているところしか取れない
- 職業のエリアへの入口は門だけ
- 門を通るにはその職業の証が要る。通っても証はなくならない
- 中身がわかるのは、取ったパネルに接する6マスまで
- 武器のエリアで取った能力は、その武器を手に持っているときだけ働く
- ラッキーパネルを取るたびにSPの上限が上がる。上限は1000
- 魔王の道へは、どの職業のエリアからでも入れる

## 操作

| 操作 | できること |
| --- | --- |
| 左ドラッグ | 盤を動かす |
| ホイール | 拡大・縮小 |
| 左クリック | パネルを選ぶ |
| ダブルクリック | パネルを取る |
| 右クリック・ESC | 戻る |

パネルの詳細の下にある「取ったパネルを全部やめる」で、取ったパネルを外せます。
