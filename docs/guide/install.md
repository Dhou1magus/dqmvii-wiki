# 導入方法

## 用意するもの

| もの | 版 | メモ |
| --- | --- | --- |
| Minecraft Java版 | 26.2 | 統合版では動かない |
| Java | 25 |   |
| NeoForge | 26.2.0.88 | MODより先に入れる |

ほかの版のMinecraftやNeoForgeには入れないでください。

## 配布ファイル

| ファイル | 中身 | 必要か |
| --- | --- | --- |
| `DQMVII-1.00.00.jar` | MOD本体 | 必ず入れる |
| `DQMVII-Voice-1.00.00.jar` | 物語の声（物語・町の人などの台詞） | なくても遊べる |
| `DQMVII-Voice-Party-1.00.00.jar` | 仲間の声（ペットと勇者の台詞） | なくても遊べる |

声のファイルは2つ合わせて約440MBです。片方だけ入れることもできます。ファイルは公式サイトのダウンロード欄から落とします。
