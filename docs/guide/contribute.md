# 情報の送り方

このサイトは管理者が編集しています。情報は、誰でも書き込めるseesaa wikiで集めています。

## seesaa wikiに書き込む

seesaa wikiは、アカウントがなくても書き込めます。seesaa wikiに書き込まれた内容は、このサイトに転写します。

[DQMVII攻略wiki（seesaa wiki）を開く](https://dqmvii.game-info.wiki/){.dq-link-button}

## 書き込むときのお願い

- ゲームの中で確かめたことを書く。
- 確かめたMODのバージョンを書く。
- まだ確かめていないことには「未確認」と書く。
- MODのファイルを解析して得た情報は書かない（利用規約で禁止されています）。
- 他のサイトの文章をそのまま写さない。
- ほかの人が書いた内容を消すときは、理由をコメント欄に書く。

## 新しいページを作るとき

ページ名は、ゲーム内で表示される名前にしてください。
モンスターのページは[モンスター/テンプレート](https://dqmvii.game-info.wiki/d/%a5%e2%a5%f3%a5%b9%a5%bf%a1%bc/%a5%c6%a5%f3%a5%d7%a5%ec%a1%bc%a5%c8)を写して作ると早いです。
