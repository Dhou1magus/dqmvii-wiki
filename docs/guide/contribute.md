# 情報の送り方

このサイトは管理者が編集しています。情報は、誰でも書き込めるseesaa wikiで集めています。

## seesaa wikiに書き込む

seesaa wikiは、アカウントがなくても書き込めます。書き込まれた情報は、確かめたうえでこのサイトにも載せます。

[DQMVII攻略wiki（seesaa wiki）を開く](https://dqmvii.game-info.wiki/){.dq-link-button}

## 書き込むときのお願い

- ゲームの中で確かめたことを書く
- 確かめたMODのバージョンを書く
- MODのファイルを解析して得た情報は書かない
- 他のサイトの文章をそのまま写さない
